# 迷路ゲームエンジン (Dxlibバージョン)
## 名前
迷路用ゲームエンジン-Dxlib Ver 1.0.0

## 説明
　このゲームエンジンは簡単なGUIゲームを制作できるエンジンです。  
  もともとの状態であればただの迷路ゲームです。  
  制作するうえでDxlibライブラリを使用しているのでlinuxでは動作しません、またコンパイルする際はお使いのコンパイラの説明をちゃんと理解して改造してください。

  ### 遊び方
    １. gui-main.exeがあるのと同じ階層にmap-gui.mapファイルがあることを確認してください。  
    ２. 1が良ければgui-main.exeを起動してください。  
    ３. ゲームの移動は、wが上、aが左、sが下、dが右の移動になります、強制終了はqです。  
    ４. ゲームはすべて64x64の画像で作られています、なので見ればわかりますが、自機は矢印です。
    ５. 鍵を入手するとログがのこります。

  ### 仕様
 　  map-gui.mapの中身はすべて数字です、プログラムを見るとわかりますがリストでマップを読み込んでいるので.mapの中身をそのリストに合わせて書く必要があいります。
  今回の場合は9x10x10で書かれたマップをを2個書いています。中身を簡単に書き換えれるので書き換えながら遊んでみてください、また付属されている.pyファイルはその.mapを簡単に制作、書き換えできるものです。
  簡単に作れますが、9x10x10のマップを1個作るものなので、別でファイルを保存し中身をコピーしてmap.mapに書き込むのがおすすめです。

  ### 動作環境
   1026/10/21時点の検証  
   コンパイラ, MinGW-W64-builds-5.0.0  
   OS, Windows 11 64bit 25H2  
   RAM, 8GB  

## 改造の仕方とプログラムの注意
　改造の仕方として、このプログラムのソースコードはgui-main.cppです、これを改造してください。  
  改造する際に気をつけてほしいのが関数で処理してるので名前が被って処理がごっちゃになるのは気をつけてください。
C++のclass管理をうまく使えてない私は馬鹿です。
